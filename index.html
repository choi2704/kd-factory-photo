USER GUIDE

사용 안내 · 데이터 보관

① 제품 / 도면 먼저 등록

특이 제작품의 이름, 규격, 주의사항을 입력하고 도면(PDF·이미지), 참고 사진을 첨부하세요. 화면에서 직접 간단 스케치도 가능합니다.

② 촬영 · 작업 일정 등록 + 도면 첨부

촬영 일정을 입력할 때 하단의 ‘이 일정의 도면 첨부’에서 이미지 또는 PDF를 직접 올릴 수 있습니다. 별도로 제품을 등록할 필요가 없습니다. 달력에서 날짜를 선택하면 도면 파일을 바로 열 수 있습니다. 기존 제품과 연결한 경우 제품 보관함의 도면도 표시됩니다.

③ 촬영 체크리스트 활용

일정마다 필요한 촬영 장면을 항목별로 입력해 두고, 촬영하면서 체크 표시하세요.

④ 개인 데이터와 백업

내용은 현재 사용 중인 브라우저 내부 저장공간(IndexedDB)에만 저장됩니다. 서버·Supabase·다른 직원의 기기와 동기화하지 않습니다. 브라우저 데이터 삭제나 PC 교체 시 사라질 수 있으므로 상단의 ‘백업 저장’을 주기적으로 눌러 JSON 파일을 안전하게 보관하세요.

※ 이 파일을 GitHub Pages에 올리면 프로그램 화면 주소 자체는 공개될 수 있습니다. 혼자만 사용하려면 PC에서 index.html 파일을 직접 여는 방식이 가장 간단합니다. 다른 브라우저나 PC로 옮길 때는 백업 파일을 가져오세요.

첨부 파일: 이미지/PDF 최대 25MB, 참고 영상 최대 60MB(파일당). 촬영한 긴 원본 영상은 별도로 보관하고 여기에는 일정·참고 자료 위주로 등록하는 것을 권장합니다.
