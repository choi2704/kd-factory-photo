강동자바라 | 개인용 도면·촬영 스케줄 관리 (v1.1)
================================================

1. 사용 방법
   ① 폴더에서 index.html 파일을 두 번 클릭하여 크롬/엣지로 열어 주세요.
   ② [＋ 제품 / 도면 등록]에서 특수 제작품의 제품명·규격·주의사항을 기록하세요.
      - 도면 사진/PDF, 참고 제품 사진·영상 첨부 가능
      - 직접 간단 스케치하여 도면으로 저장 가능
   ③ [＋ 촬영 일정 등록]에서 사진·영상·도면 확인 일정을 정하고 관련 제품을 선택하세요.
   ④ 달력에서 날짜를 눌러 해당 날짜의 촬영 체크리스트를 관리하세요.
   ⑤ [제품 · 도면 보관함]에서 자료를 찾고, [전체 촬영 일정]에서 일정을 한눈에 보세요.

2. 저장 위치 및 개인 정보
   - 로그인/공유 기능이 없는 개인용 프로그램입니다.
   - 자료는 이 프로그램을 연 브라우저의 자체 저장공간(IndexedDB)에 저장됩니다.
   - 도면·사진은 외부 서버로 보내지지 않습니다.
   - PC를 바꾸거나, 브라우저 사용 기록/사이트 데이터를 삭제하거나,
     보안 설정으로 사이트 저장소가 차단되면 내용이 없어질 수 있습니다.
   - 시크릿 모드는 사용하지 마세요.

3. 백업 / 복원 (중요)
   - 화면 오른쪽 위 [백업 저장]을 눌러 JSON 백업 파일을 보관해 주세요.
   - 브라우저를 바꾸거나 PC 교체 시 [백업 불러오기]로 복구합니다.
   - 백업 파일에는 첨부 도면·이미지·영상도 포함됩니다. 안전하게 보관하세요.
   - 복원은 현재 자료를 새 백업 내용으로 교체합니다.
   - 긴 촬영 원본 영상은 별도 폴더에 보관하는 편이 안정적입니다.

4. 파일 구성
   index.html : 화면
   style.css  : 디자인
   app.js     : 기능 및 저장
   ※ 세 파일은 같은 폴더에 있어야 합니다.

5. 참고
   이 파일을 GitHub Pages 등 공개 웹호스팅에 게시하면 프로그램 화면이
   누구에게나 보일 수 있습니다. 혼자만 사용한다면 PC에 저장하여 실행하세요.
