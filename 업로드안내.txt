강동자바라 개인용 도면·촬영 스케줄 v1.2 (GitHub Pages용)

업로드: 압축 해제 후 index.html, app.js, style.css 세 파일을 GitHub 저장소 최상위(루트)에 업로드하세요. ZIP 파일 자체를 업로드하면 사이트가 동작하지 않습니다.

기존 kd-factory-photo 저장소를 재사용할 경우 기존 공장용 파일이 남아 있지 않도록 별도로 확인하세요. 특히 config.js, supabase-common.js, factory.html 등의 기존 페이지는 개별적으로 삭제해야 합니다.

저장: 일정과 도면은 GitHub 서버가 아닌 해당 브라우저의 IndexedDB에 저장됩니다. 다른 컴퓨터에서는 보이지 않고, 브라우저 데이터 삭제/기기 변경 시 사라질 수 있습니다. 정기적으로 프로그램의 백업 기능을 사용하세요.

개인정보: 웹 사이트 화면과 소스코드는 공개될 수 있습니다. 브라우저에 저장된 개인 일정과 도면은 코드 업로드에 포함되지 않습니다.
